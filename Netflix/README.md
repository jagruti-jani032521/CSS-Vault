# 🎬 Netflix India – Homepage Clone

A front-end clone of the Netflix India homepage, created using **HTML5 and CSS3**. This project recreates the look and feel of Netflix's landing page with a dark theme, trending movies, membership information, and frequently asked questions.

## 🌟 Project Overview

This is a beginner-friendly front-end development project inspired by the official Netflix India website. It demonstrates the use of HTML and CSS to create an attractive and structured landing page.

## ✨ Features

- 🎥 Netflix-inspired navigation bar.
- 🌆 Hero section with background image and overlay.
- 🔴 Sign In and Get Started buttons.
- 🎞️ Trending Now movie poster section.
- 💎 More Reasons to Join section.
- ❓ Frequently Asked Questions section.
- 🌐 Language selection dropdown.
- 📱 Netflix-inspired dark theme.
- ✨ CSS hover effects on cards and buttons.
- 📌 Footer with useful navigation links.

## 🛠️ Technologies Used

- **HTML5** – Webpage structure.
- **CSS3** – Styling, layouts, backgrounds, and hover effects.
- **Remix Icon** – Icons and visual elements.
