Display : Flex (Child Property) Flex-Grow

  • This flex-grow CSS property sets the flex grow factor ,which specifies how much of the flex container's positive free space .if any,should be assign to the flex item's main size.
  • when the flex container's main size is larger than the combinedmain sizes of its flex items.this positive free space can br distributed amongthe flex items,which each item's growth being their growth factor valueas a proportion of the sum total of the flex items flex grow factors.

Display : Flex (Child Property) flex-shrink

  • The flex-shrink CSS property sets the flex shrink factor of a flex item. If the size of all flex items is larger than the flex container, the flex item can shrink to fit according to their flex-shrink value. Each flex line's negative free space is distributed between the line's flex items that have the flex-shrink value grater than 0.
Flex-shrink: 0;
Flex-shrink: 1;
Flex-shrink: 2;
