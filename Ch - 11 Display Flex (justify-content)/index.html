Display : Flex (Parent Property) Justify Content

  • The justify content property aligns the flexible container's items when the items do not use all available space on the main-axis(horizontally).
  • The justify content property can also be used on a grid container to align grid items in the inline direction. For pages in English, inline directon is left to right and block direction is downward.

    • flex-start in the context of CSS Flexbox refers to a value that determines that alignment of items whithin a flex container along the main axis, typically placing them at the start of the container.
