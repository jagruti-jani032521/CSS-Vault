🛒 E-Grocery Super Market

A simple and responsive-looking E-Grocery Super Market Product Listing Page built using HTML and CSS. This project showcases grocery products with product images, prices, discount labels, ratings, search UI, and sorting options.

📌 Project Overview

The E-Grocery Super Market is a front-end web development project designed to display grocery and snack products in a clean, card-based layout. It provides a basic online grocery shopping interface where users can browse products and view their prices, ratings, and available discounts.

✨ Features
🛍️ Product Listing: Displays grocery, snacks, biscuits, chocolates, and dairy products.
🏷️ Discount Labels: Highlights product discounts, sale offers, and promotional deals.
⭐ Product Ratings: Displays product ratings and review counts.
💰 Price Display: Shows product prices along with original prices.
🔍 Search Bar UI: Includes a search input with a search icon.
↕️ Sorting UI: Provides options for featured products and price-based sorting.
📦 Product Cards: Displays products in individual cards with images and details.
➕ Add Button UI: Includes an Add button on each product card.
🎨 Custom Styling: Uses CSS for layouts, spacing, colors, borders, and typography.
🔗 Remix Icon Integration: Uses Remix Icon for interface icons.
🛠️ Technologies Used
HTML5 – For the structure and content of the webpage.
CSS3 – For styling, layouts, product cards, and visual design.
Remix Icon – For search and add icons.
External Image URLs – For grocery product images.

🚀 Getting Started

Follow these steps to run the project locally.

1. Clone the Repository
git clone <your-repository-url>

2. Open the Project Folder
cd E-Grocery-Super-Market

3. Run the Project

Open index.html in your web browser.

You can also use the Live Server extension in Visual Studio Code for a convenient development experience.
