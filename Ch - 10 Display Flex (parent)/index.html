Display : Flex , Flex-Wrap

  • The flex-wrap properties specifies whether the flex items should wrap or not, if there is not enough room for them on one flex line.
  • The flex-wrap properties can have one of the following values:
    • nowrap
    • wrap
    • wrap-reverse

    • Display : Flex , Flex-Wrap : no wrap

    • The nowrap properties specifies that the flex items will nowrap

Display : Flex , Flex-Direction

  • The flex-Direction properties specifies the display direction of flex items in the flex container.
  • The flex-Direction properties can have one of the following values:
    • row
    • column
    • row-reverse
    • column-reverse

    • Display : Flex , Flex-Direction : row

    • The row value is the default value,and it display the flex items horizontaly.

Display : Flex , Flex-flow

  • The flex-flow property is a shorthand property for setting both the flex direction and flex-wrap properties.
  • The flex-flow property can have one of the following values:
    • row-wrap
    • row-wrap reverse
    • row-nowrap
    • column-wrap
    • column-wrap reverse
    • column-nowrap

    • Display : Flex-flow:row wrap;

    • The CSS property flex-flow: row-wrap: is shorthand property for setting both the flex direction and flex-wrap properties on a flex container.
